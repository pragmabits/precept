### 2.4 Type parameters

**Problem:** The `L` of `Hold[L Leased](lease L)` and the `L` of `Free[L Leased](lease L)` are different types to go/types, so the rule never bound, not even with slots. `[]T` and `map[K]V` never bound either.

**Solution:** With slots written on both sides, the types are compared by shape: pointer, slice, array with its length, map, channel with its direction, named type with its type arguments, and signature. Each type parameter of one side is paired with exactly one of the other, in both directions (`correspondence` in `paircheck/correspondence.go`). Without slots, the error adds `: a type parameter links only through a slot written on each side` (`noLink`).

**Files:** `paircheck/correspondence.go`, `paircheck/bind.go`

### 2.5 New rule keys

**Solution:** All default to `false`, are wired through `Rule` → `protocol`, and are decoded from JSON and YAML.
- **`require-defer`:** an explicit satisfier call does not discharge (`called` in `paircheck/flow.go`).
- **`idempotent`:** a repeated trigger on the proven-same value opens no second obligation.
- **`defer-first`:** while the obligation is open and no deferred satisfier covers it, a call is reported with `… deferred before any other call`.
  - Exempt: satisfiers, builtins, calls that do not return, and calls whose result only feeds the deferred satisfier's arguments (`callsBeforeDefer`, `feedsDeferredSatisfier`).
  - `search.leaks()` returns a `leak` kind (`leakAtExit`, `leakBeforeDefer`), and the message is chosen by it in `paircheck/diagnostic.go`.

**Files:** `paircheck/config.go`, `paircheck/protocol.go`, `paircheck/flow.go`, `paircheck/diagnostic.go`, `paircheck/paircheck.go`

### 2.6 Function values

**Solution:**
- **Part A, method values:**
  - `receiverOf` takes the receiver a method value binds (`boundReceiver` in `paircheck/slot.go`, the one binding of an SSA `$bound` closure).
  - A method value of a satisfier is not a closure-capture transfer, and it carries the value (`boundSatisfier`, `carries` in `paircheck/transfer.go`): stored, returned or passed along, it takes the obligation with it.
- **Part B, the `call` satisfier:**
  - `satisfiers: [call]` stands for calling the value itself when it is a function. It is compiled to `side{called: true}` (`compileSatisfier`); `call` with a slot is refused with `ErrCallSlot`.
  - The satisfier's candidate is `called` and links with any function type; the slot kind is `slotCallee`.
  - `binding.calledBy` counts only a dynamic call whose callee has exactly `binding.valueType`, so a callback of another signature is not the value.
  - `Packages` and `seesAll` skip `call`.

**Files:** `paircheck/slot.go`, `paircheck/transfer.go`, `paircheck/bind.go`, `paircheck/protocol.go`, `paircheck/config.go`, `paircheck/validate.go`, `paircheck/diagnostic.go`
