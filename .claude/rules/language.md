# Language

The project is written in English. Portuguese (pt-BR) appears where a person
outside development reads the words.

Every reader of this project is a developer: of the identifiers, the comments,
the commit messages, the documentation, the README, the session reports, the PR
descriptions, the log lines, the CLI output, a diagnostic and the error that
refuses a configuration. All of it is English.

Portuguese text carries its diacritics. `Navegação`, never `Navegacao`. A missing
accent is a spelling error, not a shortcut.

The test for a borderline string: who reads it? A person outside development
reads Portuguese. Whoever reads a diagnostic, runs the executable or configures
a rule reads English.
